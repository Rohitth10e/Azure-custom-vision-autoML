# Custom Vision Azure

A collection of Azure Machine Learning projects and demonstrations.

## Projects

- **custom-vision-model-demo** — Custom Vision model examples with sample images
- **azure-automated-ml** — Azure AutoML demonstrations and examples
- **azure-designer-ml-pipeline** — Azure ML Designer pipeline configurations
- **kaggle-ds** — Kaggle dataset samples (diabetes dataset)
- **imageset** — Training data (apple images for model training)

## Getting Started

Each project directory contains documentation and resources for exploring Azure ML capabilities.

## Tech Stack

- Azure Machine Learning
- Custom Vision API
- Python
- Kaggle datasets
